# Documents Folder

Place your source documents here. The AI agent will read these during `/setup`.

## Recommended files
- `my_cv.pdf` or `my_cv.docx` — Your current CV/resume
- `linkedin_export.pdf` — LinkedIn profile export (PDF)
- `certificates/` — Certifications and training certificates

## applications/
Each completed application is archived here automatically by the `/outcome` command:

```
applications/
  CompanyName_RoleName/
    posting.md        ← Job description snapshot
    cv_submitted.pdf  ← CV version submitted
    cover_letter.pdf  ← Cover letter submitted
    outcome.md        ← Result and notes
```
