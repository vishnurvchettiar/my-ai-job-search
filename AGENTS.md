## Workflow for New Job Applications

1. User provides a job posting (URL or text)
2. **Always evaluate fit first** before proceeding
3. If good fit: create tailored CV and cover letter
4. Prepare interview talking points

---

## Commands

| Command | Description |
|---------|-------------|
| `/setup` | Populate your profile and prepare templates |
| `/apply <url or text>` | Evaluate fit, tailor CV, draft cover letter |
| `/scrape` | Search job portals for matching positions |
| `/rank` | Batch-score scraped listings and return a ranked shortlist |
| `/interview` | Prepare for an upcoming interview |
| `/outcome <result>` | Record the result of an application |
| `/upskill` | Identify skill gaps and suggest a learning plan |
| `/salary` | Look up salary benchmarks for a role |
